# Admission maintenance barrier

When a source policy is configured, new jobs and explicit single or bulk retries are admitted only for registered sources with `admission_allowed: true`. Unknown sources fail closed. A policy-level `maintenance: true` blocks all new jobs and retries regardless of per-source flags, while queued/running jobs continue and existing idempotent submissions, status, and result reads remain available. Explicitly register an historical source before retrying its old jobs; no historical rows are changed automatically. Policy-less compatibility mode remains supported and has no maintenance guarantee.

Use authenticated `POST /v1/maintenance/admission` with the existing storage bearer token and JSON `{"enabled":true,"expected_sha256":"<sha256 of exact current policy bytes>"}`. The endpoint acquires the broker admission lock and the policy writer lock, checks the current policy checksum, and atomically commits the new flag. A successful response is a barrier for all in-process durable claims and requeues: earlier claims finish before the response; later new claims observe maintenance. The endpoint does not pause dispatch or terminate active execution. Check successful response, read back effective `GET /v1/sources`, and inspect/drain previously accepted work. External writers must use the same policy lock; manually replacing policy bytes without the endpoint does not provide an admission barrier. Use a fresh expected checksum and coordinated ownership when clearing the flag; never overwrite intervening policy changes.

Older broker releases do not implement this endpoint and continue allowing unknown sources and retries. This feature cannot fence the predecessor before its own activation. An independent reviewed ingress fence is required for predecessor rollout; a momentarily empty queue, closing only named sources, or blocking all traffic while claiming result reads remain available is not such a proof. This barrier is not remote-worker cancellation, GPU lifecycle fencing, or a guarantee that an expired lease has released memory.
